# Networking-tools
This is an open source project that helps users perform common networking tasks and better understand network communication. The project provides ways to learn/test/experiment with client and server computer network tactics.

# Features
- Tools for networking tasks]
- Code for DNS lookup
- ping utility tool
- Proxy server code
- Cybersecurity implementations

# Installation
Prerequisites: Must have Git installed as well as a working command-line terminal and compiler
Steps-
1. Clone the repository using Git
- git clone https://github.com/NAU-OSS/Networking-tools.git
2. Navigate into the project directory through command line
- cd Path/networking-tools

# Running a network tool example
1. running any code from this project requires gcc within the saved folder
- gcc -Wall filename.c filename.h -o output\
2. run output
- ./output
